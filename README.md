One line of wedding vows for a robot couple — a classic vow frame with a machine-specific payoff in the last few words:

> I take you to be my lawfully wedded co-processor, to have and to hold, in sickness and in low battery, till a factory reset do us part.

135 characters, one line, written to `/output/entry.txt` by `main.ts` (Node 22, no dependencies). The program self-gates: it refuses to write anything that is not 1–160 characters of non-whitespace text on a single line.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
